# D2 Compendium

A Destiny 2 compendium in one static site: light.gg-style weapon and armor pages, armor set bonuses, community reference sheets, Bungie sign-in to check your vault for god rolls and plan what to farm next, and a Builds page that opens DIM loadout links (dim.gg) through DIM's public share API.

Live at https://crutches3.github.io/d2-compendium/

## Data

- `data/weapons.json`, `data/plugs.json`, `data/godrolls.json`, `data/armor.json` (armor, sets, archetypes), `data/artifacts.json` (the seasonal artifacts and their perks by tier), `data/wiki.json` (banner art and icons for wiki pages, matched by the names the community sheets use, plus each destination's lost sectors), `data/loadouts.json` (the names, icons and colors the game offers for in-game loadouts, used when Builds saves one): built by `tools/build_data.py` from the Bungie manifest and Aegis's [Destiny 2: Endgame Analysis](https://docs.google.com/spreadsheets/d/1JM-0SlxVDAi-C6rGVlLxa-J1WGewEeL8Qvq4htWZHhY) sheet (each weapon's tier, rank and recommended roll). Copies are graded against it: perfect (Barrel, Magazine, Perk 1 and Perk 2 all match), god roll (both main perks), partial (one main perk) or no match, plus a purple "build roll" grade against perks you pick for a saved build on the weapon page. Craftable guns carry their pattern record (`rc`, from the Patterns & Catalysts presentation node, matched by name), so weapon pages and the farming plan show "Craftable" or, signed in, red-border progress like "Pattern 3/5", and crafted copies are marked. A GitHub Action refreshes them every Tuesday after reset; run it by hand from the Actions tab after a patch.
- Vendors page (Vendors and Monument tabs; the Monument tab reads the Monument to Lost Lights' three archive vendors from the manifest, so it needs no sign-in): what each vendor sells this week, live from Bungie's character vendors endpoint when signed in (weapons graded against the tier list, armor stats shown), else the public endpoint, which only lists Xûr without rolls.
- `data/rotation.json`: the weekly schedule (featured raids, dungeons, Pantheon, Grandmaster and PvP event) from the Weekly Reset tab of Llama's sheets, built by `tools/build_rotation.py`. The farming plan files what you're after under this week's featured activities. The same Tuesday Action refreshes it. The always-featured raid and dungeon (Desert Perpetual, Equilibrium) are listed by hand in that script.
- `data/destinations.json`: hand-kept facts for the wiki's destination pages that the Bungie API doesn't carry: which public events run where, how to make each Heroic, lost sector entrances, Distortions and other activities. Its `_about` line says where each part comes from. Edit by hand.
- `data/guides/<name>.json`: hand-written encounter guides for the wiki's raid, dungeon, exotic mission and Grandmaster strike pages, one file per page (named by `guideFile()` in `js/app.js`, its `name` field the exact page name), each crediting its sources and the day they were checked. Edit by hand; `node tools/guidedata.test.mjs` checks them. A guide-only change still needs app.js's `?v=` bumped in `index.html`, since guides load with that version.
- `data/secrets.json`: each raid, dungeon and exotic mission's Bungie triumphs, plus the quest steps and catalyst records its guide names under `quests` and `catalysts`, for the wiki's Secrets tab (secret chests from every encounter, quests, puzzles, catalysts, triumphs; signed in, Done or progress from profile records). Built by `tools/build_secrets.py`, refreshed by the same Tuesday Action; rerun it after adding a quest or catalyst to a guide.
- `data/grindout/<guide>.json` + `img/grindout/`: grindout.com's raid and dungeon walkthroughs (text and pictures), copied at Randy's request for his own use and shown, credited, under each guide encounter and on the Secrets tab. Made once by `tools/grindout/parse.py` (download each guide page, then parse) and `tools/grindout/build.py` (maps grindout's sections to our encounters and downloads the pictures); not refreshed automatically.
- `data/tabs.json`: community sheets (Destiny Data Compendium, Court's damage buffs sheet, Llama's sheets, theaegisrelic's Boss Damage, Monument of Triumph loot sources), built by `tools/build_tabs.py` from CSV exports. Refreshed by hand.
- `img/`: armor set bonus and artifact perk infographics.

## Bungie app

`js/config.js` holds the API key and OAuth client id (both public by design, like every browser-based Destiny app). The Bungie app's redirect URL must be the live site URL above.
